# imersao-revendedores-distribuidores-moura

Entrevistas com revendedores e distribuidores **Moura** — quem de fato usa
a solução Credimora hoje. Etapa intermediária entre a imersão interna
(time Propig/Moura, para entender o produto) e a imersão externa
(potenciais clientes Goodyear e Decor Colors).

## Revendas

- `2026-09-16_entrevista-revenda-01-sp-fabio_transcricao.docx` +
  `sintese_entrevista-revenda-01-sp-fabio.md` — revenda familiar, 47 anos,
  plano Sessão total.
- `2026-09-16_entrevista-revenda-02-sp-lucas-barreto_transcricao.txt` +
  `sintese_entrevista-revenda-02-sp-lucas-barreto.md` — loja nova (~1,5
  ano), plano Flex, primeira voz de usuário Flex na pesquisa.
