# mAIONESE

Projeto de pesquisa "Inside the Kitchen" (MJV para Kraft-Heinz): jornada do
chef/operador de cozinhas profissionais e panorama sensorial, dentro do
Programa de Superioridade da Maionese Quero no canal AFH (fora do lar).

Este projeto é independente da pesquisa Propig/Moura que ocupa o restante
deste repositório.

## Estrutura de pastas

- `proposta-comercial/` — arquivos referentes à proposta comercial.

Novas pastas (kickoff, imersões, campo, síntese etc.) serão criadas conforme
o projeto avançar.
