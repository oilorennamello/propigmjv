# propigmjv

Repositório de organização da pesquisa.

## Estrutura de pastas

- `kickoff/` — arquivos referentes ao momento de kickoff do projeto.
- `imersao-interna-moura/` — arquivos referentes à imersão interna (time Propig/Moura, para entender o produto).
- `imersao-revendedores-distribuidores-moura/` — arquivos referentes à imersão com revendedores e distribuidores Moura (quem de fato usa a solução hoje).
- `imersao-externa-clientes/` — arquivos referentes à imersão externa (potenciais clientes: Goodyear, Decor Colors).
- `exploracao-mercado/` — arquivos referentes à exploração do mercado.
- `benchmarking/` — arquivos referentes ao benchmarking.
- `proposta-comercial/` — arquivos referentes à proposta comercial.
- `prompts/` — histórico dos prompts (pedidos) feitos nesta conversa, um arquivo por sessão/data. Serve como registro fora do chat; no chat ficam apenas as respostas.

## Dinâmica

Cada momento do projeto tem sua própria pasta. Os arquivos relativos a cada etapa devem ser enviados para a pasta correspondente.
